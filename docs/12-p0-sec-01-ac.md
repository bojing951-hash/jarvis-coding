## 验收条件

| AC | 条件 |
|---|---|
| AC-01 | 执行后校验不得经 Shell 解释；任务无权直接指定任意命令，只能引用本地登记的可信校验配置 |
| AC-02 | 写模式授权必须存在独立审批记录；调用方填写 `approved=true` 或调用普通 MCP 工具均不能获得授权 |
| AC-03 | 审批绑定任务参数摘要；参数（cwd/mode/校验/提交范围）变更后原审批自动失效 |
| AC-04 | 执行目录必须是该项目真实路径的子路径；符号链接逃逸与跨项目访问一律拒绝 |
| AC-05 | 校验失败或未校验时不得提交；提交只包含任务声明范围内的文件 |
| AC-06 | 取消后的任务不得再触发校验或提交；无法确认终止时不得虚报 |
| AC-07 | 同一任务不得并发启动两次 |
| AC-08 | 工作流入口与普通任务走同一套权限判断，不得绕过 |
| AC-09 | 历史 `approved_at` / `approved=true` 不得被当作新授权 |
| AC-10 | 每次执行产出可追溯证据：授权记录、校验退出码、真实 commit SHA、拒绝原因 |
| AC-11 | 现有能力（项目/Agent/会话/交接/工作流）不得被本轮修复破坏 |
